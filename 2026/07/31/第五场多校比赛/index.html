K题 序列变换

题目描述

有一个长度为 $n$ 的环状整数序列 $a_0, a_1, \dots, a_{n-1}$。定义一次变换如下：

  1. 根据当前序列 $a$ 构造一个新序列 $b_0, b_1, \dots, b_{n-1}$，其中 $b_i = \text{mex}(a_i, a_{(i+1) \bmod n}, a_{(i+n-1) \bmod n})$。
  2. 将序列 $a$ 替换为 $b$。
    现在给定初始序列 $a$ 和变换次数 $k$，请你求出经过 $k$ 次变换后得到的序列。

输入描述

第一行包含两个整数 $n$ 和 $k$（$1 \leq n, k \leq 10^6$）。
第二行包含 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$（$0 \leq a_i \leq 10^9$），表示初始序列。

输出描述

输出一行 $n$ 个整数，表示最终序列，数与数之间用一个空格隔开。

L题 又一个矩阵问题

题目描述

给定一个大小为 n × m 的整数矩阵 a。
你可以进行任意多次如下操作：选择一条从 (1, 1) 出发到达 (n, m) 的路径，每次移动只能向右或向下，
然后将该路径经过的所有格子上的数值增加 1。
你的目标是使矩阵中所所所有有有元元元素素素的的的值值值均均均相相相等等等。
请求出最少需要的操作次数；如果无法达成目标，请输出 −1。

输入描述

第一行包含一个整数 T（1 ≤ T ≤ 5000），表示测试数据组数。
每组测试数据的第一行包含两个整数 n, m，表示矩阵的行数和列数。接下来 n 行，每行包含 m 个整
数，表示矩阵 a，其中第 i 行第 j 列的元素为 ai,j（−10^9 ≤ ai,j ≤ 10^9）。

输出描述

对于每组测试数据，输出一行一个整数，表示该组数据的最少操作次数。若无法使矩阵中所有数相等，
则输出 −1。

没有AC原因

没有考虑只能向下或者向右的情况只是流量相等算出来了

只能向下和向右利用前缀和算当前层每一行的和以及下一层的前缀和每个必须满足大于前一行的当前层以及小于等于相同行的当前层。
